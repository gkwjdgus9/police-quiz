# 내부망·오프라인판 (offline/)

외부 연결 없이 동작하는 `교통사고 공소권 판단 도구`입니다. 법령 원문 링크와 자동 갱신 기능을 끄고, 교통사고처리특례법 제3조·제4조 조문 전문을 파일 안에 내장했습니다. 개인정보 입력 칸이 없고 저장·전송도 하지 않습니다.

## 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 도구 본체. 이 파일 하나만 있어도 동작합니다. |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png` | 휴대 단말에서 "홈 화면에 추가"할 때 쓰는 이름·아이콘 |
| `sw.js` | 오프라인 캐시. https 주소로 접속할 때만 동작합니다. |

## 배포 방법

1. **파일로 쓰기 (가장 간단)**: `index.html`을 내부망 PC나 단말에 복사해 두고 열면 됩니다. 인터넷이 없어도 모든 기능이 동작합니다.
2. **인트라넷 게시**: `offline/` 폴더 전체를 내부 웹서버에 올리고 `index.html` 주소를 공유합니다. 휴대 단말 브라우저에서 접속한 뒤 "홈 화면에 추가"를 누르면 앱처럼 실행됩니다.
3. **오프라인 캐시까지 쓰려면**: 2번 주소가 `https://`여야 합니다. 한 번 접속한 뒤에는 네트워크가 끊겨도 열립니다. 일반 `http://` 내부망에서는 캐시 없이 동작하며 접속할 때마다 서버에서 불러옵니다.

## 갱신 방법

1. 외부망에서 `traffic-check.html`을 고치거나 `law-data.json`(국가법령정보센터 자동 갱신본)을 받습니다.
2. `node scripts/build-offline.mjs`를 실행하면 `offline/` 폴더가 다시 만들어집니다.
3. 새 `offline/` 폴더를 내부망으로 반입합니다. 서비스워커 캐시는 파일 버전이 바뀌면 자동으로 교체됩니다.

`law-data.json`이 없으면 `law-data.seed.json`(수작업 전사본)이 내장되며, 화면에 "검수 필요" 표시가 나옵니다. 전사본은 국가법령정보센터 원문과 대조한 뒤 사용하십시오.

## 단말 호환

- 최신 문법(옵셔널 체이닝 등)은 쓰지 않았고 외부 라이브러리와 웹폰트가 없습니다. 2018년 이후 안드로이드 Chrome/WebView(버전 60 이상)와 iOS Safari 12 이상에서 동작합니다.
- 더 오래된 단말에서 화면이 비어 보이면 기종과 브라우저 버전을 알려주시면 호환 빌드를 만들 수 있습니다.

## 내부망 반입 전 확인

- 각 청의 정보보안 규정에 따른 반입 절차(매체 검사 등)를 따르십시오.
- 법률 내용은 교통조사 담당 부서의 검수를 거친 뒤 배포하십시오. 화면 하단의 안내 문구처럼 이 도구는 참고자료이며 최종 판단은 담당자가 합니다.
